# Proyecto3 - Inventario Android

## Descripción
Aplicación móvil nativa desarrollada en Android Studio con Kotlin para gestionar productos de un inventario.

## Funcionalidades
- Inicio de sesión mediante autenticación biométrica.
- Menú principal para acceder a las funciones.
- Registro de productos.
- Consulta del inventario mediante RecyclerView.
- Edición y eliminación de productos.
- Validación de los campos del formulario.
- Almacenamiento de productos con Firebase Firestore.

## Datos de los productos
Cada producto puede incluir nombre, categoría, cantidad, precio y descripción.

## Tecnologías
- Kotlin
- Android Studio
- XML
- ViewBinding
- RecyclerView
- Firebase Firestore

## Requisitos
- Android Studio.
- JDK compatible con la configuración del proyecto.
- Configuración de Firebase para utilizar Firestore.

## Ejecución
1. Abrir el proyecto en Android Studio.
2. Configurar Firebase con el proyecto correspondiente.
3. Sincronizar Gradle.
4. Ejecutar la aplicación en un dispositivo Android compatible.
